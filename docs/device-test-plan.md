# iPhone実機検証手順

実行状態：未実施。シミュレーターや机上調査で代替できない検証として管理する。必ず安全な停車状態で実施。

## 準備

1. `npm ci`、`npm run ios -- --device`でDevelopment Buildをインストール。Apple Team/署名は所有者の設定を使用する。
2. iPhone機種、iOS、MONOTEコミット、Audible版、地域、Siri言語（日本語）、Bluetooth機種、画面ロック状態を記録。
3. MONOTEに2冊登録、現在の本を選択。マイク・音声認識を許可。日本語オンデバイス対応状態を確認。
4. 機内モードでも音声認識を試す。ネットワーク復帰で密かにクラウド認識へ切り替えないことを確認。

## Phase 1 / テキスト管理

| 手順 | 合格条件 |
| --- | --- |
| 本追加、著者、写真選択、編集、再起動 | 全項目と永続表紙が維持される |
| 本を切り替える、存在しないIDを開く | 現在の本は最大1冊、対象なしを表示して落ちない |
| メモ作成、編集、検索、削除 | 正しい本に紐づく。作成日時を維持、更新日時が変わる |
| 入力途中に戻る・再起動 | 新規テキスト下書きを復元できる（350ms debounce後） |
| 本を削除 | 確認を表示、関連メモ・下書きを削除、他の本は維持 |
| ライト/ダーク、大きな文字、狭いiPhone、VoiceOver | 読める、操作名が伝わる、スクロールで全機能へ届く |

## Phase 2 / 音声入力

| 手順 | 合格条件 |
| --- | --- |
| 日本語を話す | リアルタイム表示、音量に応じた表示、録音状態が明示される |
| 内容→0.8秒以上の間→「メモ終了」→1.2秒以上の間 | コマンドを除いて一度だけ保存、保存音声確認 |
| 「ここでメモ終了と言っていた」「メモ終了の方法」 | 文中の言葉では終了しない |
| 「メモ終了」を単独で発話し本文なし | 空メモを作らない、結果を知らせる |
| 無音終了ON（3/5/15秒）、OFF | 設定どおり。雑音の影響も記録する |
| 55秒上限、認識サービスが先に終了 | 保存または下書き保護。録音が残らない |
| マイク拒否、音声認識拒否、制限、非対応 | 理由を明示、音声送信せずテキスト入力が可能 |
| 通話、画面ロック、ホーム移動、Bluetooth切断 | 入力終了、部分文字列を下書き保護 |
| 認識中に強制終了し再起動 | 最後に保存できた部分文字列をnative backupから復元 |
| 保存失敗（空き容量不足等）、再試行 | 成功の誤通知なし。下書きを後で一度だけ保存 |

## Phase 3 / Siri（App Intent実装後）

アプリ内ボタンでの録音成功を先に確認。現在のビルドにはIntentなし。

1. ショートカット一覧に「メモ開始」が現れるか確認。
2. 「Siri、モノートでメモ開始」から操作なしで音声入力になるか確認。
3. foreground / background / cold start × unlocked / lockedで実施。
4. Siri終了とMONOTEマイク開始の時刻、合図、先頭音声が欠けるかを記録。
5. 本未選択、権限未許可、二重呼び出し、期限切れ開始要求を試す。
6. ロック解除やタッチが必要なら、その組み合わせはハンズフリー不成立として記録する。

## Phase 4 / Audibleとの一連の動作

本体 / AirPods / 車載Bluetoothの各経路で以下を実施。

1. Audibleで再生位置・章を記録して再生。
2. 現在はMONOTEアプリ内で開始。Intent実装後はSiri開始を追加。
3. Audibleが止まるか、入力経路が切り替わるか、本文に再生音が混入するかを確認。
4. 日本語メモを話し、「メモ終了」で保存。正しい本、コマンド除去、重複なしを確認。
5. 保存確認音声が終わった後、Audibleの復帰有無・復帰位置・遅延を記録。
6. 復帰しない場合、ユーザーのSiri発話による再生を試す。巻き戻しは未実装のため実行済みと扱わない。
7. Bluetooth切断、再接続、着信、Siri誤認識時も繰り返す。
