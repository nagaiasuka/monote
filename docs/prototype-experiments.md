## 開始が不安定な点の修正

- 保存処理中に開始要求を消費して捨てていた箇所を修正。完了まで要求を保持。
- 開始の合図後に一時的に非activeになっても、30秒の期限内なら復帰を待つ。
- 録音開始結果を確認し、対象UUIDの要求だけを削除。新しい要求を誤って削除しない。
- `received / ready / cue / start / started / failed / expired`の段階を診断ログと検証画面で確認可能。
- この修正後の反復成功率はまだ未測定。Siriがアクション自体を選ばないケースと、アプリ内の失敗を分けて確認する。
