# 音声入力の即時終了対策（2026-10-13）

ユーザーから「開始直後に終了する」と報告。コードには全てのAVAudioSession.routeChangeNotificationで録音を終了する処理があり、アプリ自身のsetCategory / setActiveによる通知も終了条件になっていた。実機で今回の終了理由そのものはまだ採取できておらず、この処理を原因と断定はしない。

修正:

- 録音開始時の入力ポートを記録し、実際にその入力が切り替わった・失われた場合だけ終了する。
- カテゴリ設定の通知や、入力が変わらない出力だけの接続・設定変更では終了しない。遅れて届く通知のpreviousRouteは比較基準に使わない。
- 終了理由を音声画面に表示。
- ネイティブログに開始、終了理由、経過秒数、認識エラーのdomain / codeを記録。本文や音声はログへ記録しない。
- 無音終了設定（初期5秒）と55秒上限は変更していない。

検証:

- 終了コマンド: 7/7成功。
- 入力切替判定: 初期カテゴリ設定、出力のみの変更、Bluetoothマイク切断、入力消失、設定通知など7/7成功。
- TypeScript型チェック: 成功。
- 実機向け最終Debugビルド: 成功。
- アプリ権限説明と11バイナリ依存検査: 成功。
- 実機での録音継続と終了コマンド・保存は、修正版で再確認が必要。まだ成功として扱わない。
